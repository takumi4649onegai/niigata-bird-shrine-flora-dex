## 📌 現在非表示・保管中の機能一覧

### 1. 📕 地域別マイ写真集（フォトブック生成）
- **保管場所**:
  - `神社仏閣・絶景・花図鑑/js/camera-enjoy-suite.js` 内、および各図鑑のIndexedDBストレージ連動コード
- **元の機能内容**:
  - GET登録した「野鳥」「神社仏閣」「四季の花」のマイ写真を地域別（下越・中越・上越・佐渡）やテーマ別にまとめ、デジタル写真集としてめくって鑑賞・振り返りができる機能。
- **非表示にした経緯**:
  - メニュー項目が多く煩雑になっていたため、ユーザー様のご指示（「一旦隠しといてください」）によりメニューバーから非表示化。
- **現在のステータス**:
  - コード・ロジックは完全維持。ボタンのみHTMLから非表示。

### 2. 🖼️ 日本の美・ポストカード／2L判プリント用デザイン書き出しスタジオ
- **保管場所**:
  - `神社仏閣・絶景・花図鑑/js/camera-enjoy-suite.js`（`renderPostcardSubView` / `drawPostcardPreview` / `downloadPostcard`）
- **元の機能内容**:
  - 撮影した写真を選び、「美術館ギャラリー白枠」「漆黒＆金文字」「越後和紙＆朱印落款（新潟寫眞など）」の額装パネルを自動生成し、高解像度PNGで書き出す機能。
- **非表示にした経緯**:
  - ユーザー様のご指示（「ポストカードは別にまだいい」）によりメニューから非表示化。
- **現在のステータス**:
  - コード・Canvas描画ロジックは完全維持。ボタンのみ非表示。
